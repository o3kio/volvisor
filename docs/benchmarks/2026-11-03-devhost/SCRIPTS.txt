----------------------------------------------------

`binary_sha256: 04c06df8d0fe288127b634b8616845f35033ba6ef2d3011647824315745b472c`.
That line was written before `cargo build` ran, so it describes a stale
pre-build artifact. The binary that actually executed the run is

recorded in ENVIRONMENT.txt and SECTION 3 of REPORT.md. The harness now
re-stamps the header after the build; this bundle keeps the original raw log
unmodified and discloses the discrepancy instead of rewriting it.
