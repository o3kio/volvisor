# Control-plane benchmark evidence — 2026-11-04 post-fix, single-host development lab

This bundle records a re-run of the issue
[#43](https://github.com/o3kio/volvisor/issues/43) harness **after** the
Phase C state-substrate fixes (`#62`, `#63`, `#64`) and
[ADR-0012](../../adr/0012-monotonic-attachment-generation-fence.md). It is the
valid post-fix measurement; it supersedes the preliminary `ec6f9df` run and
replaces the invalid pre-fix `331391e` conflict storm. It is a **single-host
development-lab**
record: one `volvisord` on one host, a disposable loop-backed LVM volume
group, control-plane HTTP only. It is **not** production evidence, **not** a
data-path benchmark, **not** an SLA, and **not** the issue's 24-hour soak (a
shortened 25-minute soak ran).

## What this run verifies

The run exists to check that the state-substrate fixes behave under sustained
churn, not to establish capacity:

- **Attachment churn is no longer refused.** The soak completed 361,726
  attach, 361,725 report and 361,723 detach operations with **0**
  `IDEMPOTENCY_CONFLICT` and 0 HTTP errors. The pre-fix run
  ([invalid-run artifact](../2026-11-04-devhost-invalid-prefix/README.md))
  recorded 1,413,505 spurious conflicts on 1,425,668 attach attempts.
- **Provider state no longer grows with attachment history.** End state is
  **3,055 bytes** (delta **−173 bytes** over the soak, max 3,675 bytes),
  versus 2,522,793 bytes before. The retired-id filter is no longer written or
  consulted (ADR-0012).
- **The journal stays bounded.** End journal is **27,982,748 bytes** (delta
  **−30,500,383**), max **75,497,833 bytes**, versus 271,399,822 bytes before.
- **Restart replay is healthy.** The mid-soak restart listed 4/4 volumes in
  **0.552 s** with unchanged state and journal sizes; pre/post-soak restarts
  recovered in 0.102–0.391 s.
- **The generation fence is exercised by the day-2 and conformance suites**,
  not by this harness. This harness is a load generator; correctness evidence
  is the test suite at the recorded SHA.

## What it also exposed (open residuals)

These are findings, not fixes, and they are not production claims:

- **RSS high-water remains high.** RSS rose from 169,152 KiB to 1,950,048 KiB
  (delta **+1,780,896 KiB**) and peaked at **2,323,028 KiB** during
  compaction. That is consistent with allocator/compaction transients, but a
  leak is neither proven nor ruled out. No RSS cap or fix is claimed.
- **The default INFO daemon log is unbounded.** The 25-minute run produced
  **2,572,981,477 bytes** (≈2.4 GiB) and **9,072,853** lines
  (9,072,376 INFO, 477 WARN) with no rotation. The committed copy is
  `raw/daemon.daemon.log.gz` (77,732,175 bytes compressed). Logging volume is
  an operational finding, not a durable-state defect.
- **The 25-minute soak is not the 24-hour soak.** The 24 h soak is **NOT
  RUN**.

## Capacity in one line

At 30 s per tier with the product default admission cap of 256, measured
throughput was **1952.155 ops/s at 1 in-flight**, **3493.445 ops/s at 8**,
**862.937 ops/s at 32**, and **235.502 ops/s at 128**; p95 latency was
**1.357 ms → 5.928 ms → 200.594 ms → 1349.487 ms** respectively. The
25-minute soak sustained **3616.49 ops/s**. See [REPORT.md](REPORT.md) §4–§5
for the full tables and §9 for caveats.

## What this bundle is not

- **Not production evidence** and not a support-matrix change.
- **Not multi-host.** There is no second physical host, no real Ceph, no
  DRBD, no physical-disk LVM, and no independent failure domain.
- **Not a data-path benchmark.** No guest I/O, no block-data proxying, no
  filesystem or fio workload, no disk IOPS/latency.
- **Not the 24-hour soak.** The shortened soak ran for 25.0 minutes, with one
  mid-run restart.
- **Not an SLA or capacity plan.** All numbers are one host, one loop-backed
  VG, one process. The loop image and the journal/state files share the same
  ext4 filesystem.
- **Not a durability proof.** It exercises acknowledged control-plane writes;
  it does not prove crash consistency or data-path durability.

Percentiles are nearest-rank over every recorded request. The `*-ops.csv`
files are a deterministic prefix sample (first 5,000 requests per operation);
the JSON aggregates are exact. The run token was replaced with `<redacted>`
in `configs/`; the bundle has no bearer or claim token.

## Reproduction

```bash
sudo scripts/bench/run-all.sh \
  --run-dir /tmp/opencode/volvisor-bench-phasec-final-20261104 \
  --skip-build --sweep-seconds 30 --soak-minutes 25
```

The run directory named above is the workspace copy used to build this
bundle; the committed bundle is the durable evidence copy. Verify the bundle
with `sha256sum -c MANIFEST.sha256`. Re-generate the comparison with:

```bash
python3 scripts/bench/compare.py \
  --before docs/benchmarks/2026-11-03-devhost \
  --after docs/benchmarks/2026-11-04-devhost-postfix \
  --out /tmp/opencode/phasec-compare
```
