Post-run tools
--------------
scripts/bench/publish.sh copied the run directory into this bundle, redacted
the run token in configs/, and gzip-compressed the oversized daemon log
(2.2 GiB raw) with `gzip -9 -n`. It does not alter any measured JSON or CSV.

scripts/bench/compare.py generated comparison/comparison.md and
comparison/comparison.csv from this bundle and the
2026-11-05-devhost-capacity-domain-fix bundle. It verified both
MANIFEST.sha256 files before reading records. It was not part of the load
generation and does not change the measurement.

The authored README.md, REPORT.md and this file were written after the run
from the run's raw records; they add no measured values.

capacity, SLA, durability or data-path evidence. The mixed sweep is not a
fixed-dataset comparison. The 24-hour soak is NOT RUN. The c128 aggregate
