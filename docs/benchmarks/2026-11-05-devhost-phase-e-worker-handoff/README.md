# Control-plane benchmark evidence — 2026-11-05 Phase E worker handoff, single-host development lab

This bundle records the clean-tree re-measurement of the Phase E
create/delete write path at
`7204a53198457bf69aa9797db67708a696270142` (`volvisord 7204a53`). It adds
the create/delete worker handoff and the cross-kind/reservation gate
coverage to E1/E2 (`8cfa4c2`, `2c5b065`). It is a **single-host
development-lab** record: one `volvisord` on one host, a disposable
loop-backed LVM volume group, control-plane HTTP only. It is **not**
production evidence, **not** a data-path benchmark, **not** an SLA, and
**not** the 24-hour soak (a shortened 25-minute soak ran).

## What this run verifies

The run exists to measure the `7204a53` tree with the same 1/8/32/128 sweep
and 25-minute soak as the prior runs, and to confirm the build and test
evidence at that SHA. It does not demonstrate the handoff's liveness
benefit, because the timed sweep and soak contain no concurrent
create/delete.

- **Micro create/delete are flat.** create p50 **194.991 → 195.561 ms
  (+0.29%)**, p95 **215.837 → 215.488 (−0.16%)**; delete p50
  **154.492 → 154.685 (+0.12%)**, p95 **174.464 → 174.961 (+0.28%)**. At
  concurrency 1 the handoff adds no measurable per-op overhead in this
  sample.
- **The mixed sweep is mixed, and c128 fell sharply in this sample.** c1
  **1,822.948 → 1,837.885 (+0.82%)**, c8 **3,756.659 → 3,824.485
  (+1.81%)**, c32 **2,476.245 → 2,436.350 (−1.61%)**, c128
  **610.988 → 462.899 (−24.24%)**. The timed sweep has no create/delete and
  the binary differs only in the two create/delete wrappers, so the c128
  drop is **not attributed to this slice**. A non-evidence alternating
  diagnostic found c128 varying from **427.5 to 626.0 ops/s** across runs
  of both binaries, with adjacent different-arm runs within 1.6%; the tier
  is variance-dominated on this host. See
  [diagnostics/c128-variance/README.md](diagnostics/c128-variance/README.md).
  No gain and no zero-regression claim is made.
- **The c128 write p95 is not like-for-like.** Aggregate write p95
  **4,297.266 → 9,151.103 ms**, but the grow share of writes rose
  **5.36% → 7.22%**, moving the p95 from about the 7th to the 31st
  percentile of the grow distribution. Grow's own p50/p95 improved
  **10,390.696 → 9,719.410 ms** and **22,079.170 → 18,123.642 ms**. The
  aggregate rise is a composition/quantile effect.
- **The shortened soak rose 7.32%:** **6,626,734 → 7,112,020 ops** and
  **4,417.815 → 4,741.344 ops/s**. It recorded 72 network errors
  (70 `ConnectionRefusedError`, 2 `RemoteDisconnected`) at the planned
  restart, no provider or HTTP errors. The soak contains no create/delete;
  the difference is not attributed to this slice.
- **Restart replay is healthy.** All `OK`; mid-soak 4/4 volumes in 0.546 s,
  pre-soak 0.081–0.103 s, post-soak 0.506–0.507 s.
- **Gate tests cover the new paths.** The E1/E2 gate tests now exercise
  same-kind and cross-kind refusal, and prove the create reservation is
  released on completion (a 4 MiB create fits in the 8 MiB left only if the
  departed create's 1 GiB promise is gone). Negative controls were
  reproduced for both new assertions.
- **Provider state stays bounded** at 3,485 B end; the journal ended at
  41,194,835 B. RSS peak was 2,842,396 KiB (vs 2,492,976 KiB); a leak is
  neither proven nor ruled out. The raw daemon log has 0 ERROR and 1,548
  WARN, all the known grow-notification retry for attachments without a
  `vmm_disk_id`.

## What it also exposed (open residuals)

These are findings, not fixes, and they are not production claims:

- **Create/delete still retain short in-lock steps.** Delete's `lvs`
  existence check and create's `pick_pool_vg` `vgs` sample remain inside
  their admission critical sections; the failed-create compensation's
  `lvremove` remains inside the reacquired critical section.
- **The c128 tier is variance-dominated in this lab.** A single c128
  sample cannot support a throughput or regression claim. The non-evidence
  alternating diagnostic is included only to show that range; it is not
  evidence.
- **The c128 grow queue/tail is unresolved** and LVM-per-VG-bound; this run
  did not improve it.
- **No same-SHA repeat was used** to select, replace or support the measured
  sample. The only repeat is the explicitly non-evidence diagnostic above.
- **The 25-minute soak is not the 24-hour soak.** The 24 h soak is **NOT
  RUN**.

## Measured envelope in one line

At 30 s per tier with the product default admission cap of 256, measured
throughput was **1,837.885 ops/s at 1 in-flight**, **3,824.485 at 8**,
**2,436.350 at 32**, and **462.899 at 128** (completion-inclusive; the
first-30 s sample at c128 completed 625.8 ops/s). Overall p95 latency was
**1.449 → 7.372 → 46.539 → 144.116 ms**. The 25-minute soak sustained
**4,741.344 ops/s**. The c128 number is a single-sample measurement of a
variance-dominated tier and is not a property of the change.
