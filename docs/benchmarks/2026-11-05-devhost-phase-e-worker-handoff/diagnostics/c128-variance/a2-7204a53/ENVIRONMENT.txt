Lab construction
----------------

  recorded in records/lab.vg and teardown names only that VG.
- The LVM provider skips loop devices in discovery, so lvm-state.json
  is pre-seeded with a lab-only operator device claim pointing at the
  loop device. This is a lab scaffold, not a production claim path.
- Journal and provider state live under the run directory on the same
  ext4 filesystem as the loop image; every acknowledged append uses
  the daemon implementation (fsync), never a mock.
