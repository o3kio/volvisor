Measurement caveat
------------------
This is a single-host, loop-backed-LVM control-plane run, not production
capacity, SLA, durability or data-path evidence. The mixed sweep is not a
fixed-dataset comparison. The 24-hour soak is NOT RUN. The c32/c128 recovery
is measured against the run that recorded the regression; that is not a
blanket throughput claim.
