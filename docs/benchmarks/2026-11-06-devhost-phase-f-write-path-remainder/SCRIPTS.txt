Post-run tools
--------------
scripts/bench/publish.sh copied the measured run's records (raw/csv/json/
summary, ENVIRONMENT.txt, the named records files and sanitized configs)
into this bundle. It redacted the run token in configs/ and gzip-compressed
the oversized daemon log (2,368,209,578 bytes = 2.37 GB / 2.21 GiB raw) with
`gzip -9 -n` to 62,295,235 bytes = 62.30 MB / 59.41 MiB. It copies,
sanitizes and compresses only; it does not alter any measured JSON or CSV.
It exited 0, so its token-redaction check passed. It warned that REPORT.md
was absent, which is expected at publish time.

The 59.41 MiB gzipped daemon log and the per-operation `csv/` trees were
removed from the published bundle afterwards to keep the pull request small.
They were not measured values, and no JSON aggregate, summary table or
comparison output was changed by the removal.

scripts/bench/compare.py generated comparison/comparison.md and
comparison/comparison.csv from this bundle and the
2026-11-05-devhost-phase-e-worker-handoff comparator. It verified both
bundle MANIFEST.sha256 files before reading records, exited 0 and emitted no
warning. It was post-run tooling only: it did not participate in load
generation and does not change the measurement.

The comparison, the non-evidence diagnostic, this file and the authored
README.md/REPORT.md were written after the run from the run's records;
they add no measured values.
