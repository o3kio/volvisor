Lab construction notes
----------------------
- LVM labs use loop-backed volume groups created with pvcreate/vgcreate.
  The LVM provider deliberately skips loop devices during discovery, so the
  harness seeds an operator-provisioned device claim (`role: native_pool`)
  into lvm-state.json pointing at the loop device. This is a lab scaffold,
  not a production device-claim procedure.
- ENOSPC labs use 256 KiB tmpfs mounts for the journal directory or the
  provider state directory. The journal was padded with real volume creates
  until the last-page slack was small enough that the next appended record
  encountered ENOSPC. See the D5 section of REPORT.md.
- All tokens, curl configs and private keys were created under the run's
  working directory outside the repository. They are not part of this
  bundle. Only raw command output and non-secret records were copied.
