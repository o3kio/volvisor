Notes
-----
- All builds are debug profile (`cargo build` with no `--release`).
- The version stamp is `git describe --tags --always --dirty`; no release tag
  exists at either commit. Because a tagged commit's stamp can omit the SHA,
  the drill asserts build-worktree HEAD equality rather than SHA containment.
- The D2 drill captures its binary digest *after* its `cargo test -p
  volvisord` step, immediately before starting the daemon, so the record
  cannot name a binary that the test build replaced.
- OLD and NEW were removed with their disposable worktrees after the run.
- Binary identity was captured at run time into records/d1-binaries.txt,
  records/d2-binaries.txt and records/d2live-binaries.txt. Every daemon start
  line in the raw logs also records the binary path and sha256.
