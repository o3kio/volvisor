**Smoke note.** `packaging/smoke.sh` expects the built package in the current
directory and the repository's `packaging/smoke.sh` available to the
container. The commands above bind-mount the repo's `packaging/` directory
read-only; the release workflow instead runs
`sh ../packaging/smoke.sh "$DESCRIBE" "$VERSION"` from the artifact
directory. Both shapes exercise the same script. The host network was
required only because this container runtime could not resolve distribution
repositories through its default network; it does not change what the smoke
asserts.

**Stamp note.** The `volvisord` version test compares the compiled-in stamp
with a live `git describe`. Rebuild after any working-tree change before
running the full suite: a docs edit alone makes the tree dirty and makes the
old compiled stamp stale, which is a test-harness observation, not a source
failure. The run above was taken at a clean `620b8f7` after a fresh build.
